# NubeComics APP

Una aplicación Android para gestión de cómics desarrollada con Kotlin y siguiendo el patrón de arquitectura MVVM.

## Características

- Interfaz moderna desarrollada en Kotlin
- Arquitectura MVVM (Model-View-ViewModel)

## Tecnologías utilizadas

- **Lenguaje**: Kotlin
- **Arquitectura**: MVVM
- **Build System**: Gradle
- **IDE**: Android Studio

## Requisitos

- Android Studio Arctic Fox o superior
- SDK de Android 21+
- Kotlin 1.8+

## Instalación

1. Clona este repositorio:
   ```bash
   git clone https://github.com/Irina0497/NubeComics-APP.git
   ```

2. Abre el proyecto en Android Studio

3. Sincroniza el proyecto con Gradle

4. Ejecuta la aplicación en un dispositivo o emulador Android
